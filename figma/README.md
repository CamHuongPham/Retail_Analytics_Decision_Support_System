# Figma – User Flows & Wireframes

This Figma file contains the user flows and wireframes designed for the **Retail Analytics Decision Support System (RADSS)**.

## Pages

### 1. User Flow

The page contains three business user flows:

- **User Flow 1 – Generate Seasonal Sales Forecast**  
  Sales Manager uses the system to review seasonal sales patterns and generate forecasts for upcoming sales planning.

- **User Flow 2 – Analyze Customer Value**  
  Marketing Manager uses the system to analyze customer value, segment customers, and identify high-value customer profiles.

- **User Flow 3 – Evaluate Product Performance**  
  Product Manager uses the system to evaluate product performance, identify core products, and support product prioritization.

### 2. Wireframes

The page contains four dashboard wireframes:

- **Wireframe 1 – Sales Analytics Dashboard**
- **Wireframe 2 – Sales Forecast**
- **Wireframe 3 – Customer Analytics**
- **Wireframe 4 – Product Analytics**
