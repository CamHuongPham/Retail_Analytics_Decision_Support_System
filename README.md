# Retail Analytics Decision Support System (RADSS)

A portfolio project demonstrating business requirements analysis and documentation for a retail analytics decision support system.

## Project Overview

The project analyzes retail transaction data to identify business needs and translate analytical insights into structured system requirements for management decision support.

The proposed system focuses on three key areas:

- Sales analytics and seasonal sales forecasting
- Customer value analysis and segmentation
- Product performance evaluation and prioritization
